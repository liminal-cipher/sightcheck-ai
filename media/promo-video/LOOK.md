# LOOK — 시야체크 홍보 영상 룩 카드

영상 전체의 시각 규칙입니다. 새 장면을 만들거나 고칠 때 이 파일을 먼저 확인합니다.

## 포맷

- 1920×1080, 60fps (초안 30fps), H.264 yuv420p, BT.709
- 길이 약 54초, 120 BPM (1박 0.5초, 1마디 2초). 컷은 박자 위에서만 바꿉니다.

## 색 (앱 `src/style.css`에서 가져옴)

| 토큰 | 값 | 쓰임 |
| --- | --- | --- |
| paper | `#f4f5f3` | 밝은 장면 배경 |
| white | `#ffffff` | 카드 |
| ink | `#171a22` | 제목, 로고 |
| text | `#242730` | 본문 |
| muted | `#7a7e82` | 보조 문구 |
| border | `#e7e9e5` | 카드 테두리 |

| lavender | `#b5a0ef` / `#8c72a5` | 비교 좌석 B |

| stage | `#151922` | 3D 공연장 배경 |

한 화면에 강조색은 lime 하나를 기본으로 하고, 비교 장면에서만 lavender, 가림을 설명할 때만 risk를 씁니다.

## 글꼴

- Pretendard Variable (OFL). 제목 700~800, 본문 500, 자간 제목 -0.035em.
- 영문 eyebrow는 대문자 600, 자간 0.2em (앱의 `SELECT YOUR PERSPECTIVE` 스타일).
- 숫자는 `font-variant-numeric: tabular-nums`로 카운트 시 흔들리지 않게 합니다.
- 실제 UI 캡처는 앱과 같은 Noto Sans KR로 찍습니다.

## 모션

이징은 아래 세 가지만 씁니다. 코드에서는 `src/engine.js`의 `appear()`, `move()`, `vanish()`입니다.

| 종류 | 곡선 | 언제 | 길이 |
| --- | --- | --- | --- |
| 등장 | `cubic-bezier(0, 0, 0, 1)` | 화면 밖이나 투명한 상태에서 들어올 때만 | 0.5초 안팎 (0.3~0.6초) |
| 이동 | `cubic-bezier(0.65, 0, 0.35, 1)` | 이미 보이는 요소의 위치·크기·회전·값 변화, 카메라, 선 그리기 | 장면에 맞춤 |
| 퇴장 | `cubic-bezier(0.55, 0, 0.9, 0.45)` | 화면 밖으로 나가거나 완전히 사라질 때. 끝나는 순간 불투명도 0 또는 화면 밖 | 0.3~0.45초 |

- 오버슈트(back), 탄성, sin 흔들림처럼 세 곡선 밖의 움직임은 쓰지 않습니다.
- 자막 교체는 앞 줄이 완전히 퇴장한 뒤 다음 줄이 등장합니다. 장면 끝에서 퇴장이 도중에 잘리지 않도록 시작 시각을 계산합니다(`exitBy`).
- 퇴장 애니메이션이 없는 요소는 박자에 맞춘 컷으로 장면과 함께 바뀝니다.
- 문자: 단어 단위 마스크 슬라이드업, 단어 간 0.06초.

## 금지

- 글로우, 네온, 파티클, 렌즈 플레어, 글래스모피즘, 무지개 그라디언트.
- 크로스페이드 남발(장면 전환은 컷, 매치 컷, 마스크 와이프).
- 지어낸 수치, 제휴사 로고, 실제 공연장·공연 이름.
- "정확한 시야 보장", "99%" 같은 검증되지 않은 주장.

## 정직성 규칙

- 영상 속 수치(69%, 100%, 84%, 325개, 20석)는 모두 앱의 `analyzeSightline` 결과를 영상 렌더 시점에 직접 계산해 넣습니다.
- 수치 옆에는 "가상 모델 기준" 또는 "가리지 않은 표본"을 표기합니다.
- 엔드카드에 "가상 공연장 시제품" 고지를 넣습니다.
