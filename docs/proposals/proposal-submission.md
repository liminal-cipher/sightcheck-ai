# 시야체크 AI 공연별 좌석 시야 검증 서비스

## 1. 아이디어 개요

공연을 예매할 때 같은 가격대의 좌석도 난간, 기둥, 무대 장치 때문에 관람 경험이 달라진다. 그러나 평면 좌석도와 ‘시야 제한 가능’이라는 문구만으로는 가림 정도를 판단하기 어렵다. 티켓링크의 시야제한석 안내도 가림 원인은 제시하지만 좌석별 시점을 비교하기는 어렵다. 시야체크 AI는 공연장 자료로 3D 시야 초안을 만들고 실제 사진으로 검증하여, 관객이 **예매 전에 가림 원인과 확인 수준을 알고 좌석을 고르는 서비스**다. **사용 시나리오:** 공연장 예매·고객지원 담당자는 판매 기간 매일 오전 좌석 문의와 무대 배치 변경을 검토하고, 관객은 공연을 예매할 때마다 좌석 시야를 비교한다.

## 2. 아이디어 상세 내용 및 차별성

관객은 공연·회차와 예산을 고른 뒤 좌석도에서 후보 두 자리를 선택한다. 화면을 벗어나지 않고 두 좌석의 눈높이 시점, 가려지는 무대 영역, 가격, 공식 예매처를 나란히 비교한다. ‘실제 사진으로 검증’, ‘3D 추정’, ‘자료 부족’ 표시를 함께 보고 선택하며, 예약 버튼은 해당 공연의 공식 예매처로 연결된다. 예를 들어 같은 가격의 2층 두 자리 중 한쪽은 난간이 무대 하단을 가린다는 사실을 구매 전에 알 수 있다. 현장 자료나 예매처 제휴가 없는 좌석은 가용 좌석·가격을 실시간 정보처럼 표시하지 않는다.

운영자는 좌석 배치도와 공연장 사진, 기준 치수를 등록한다. AI가 구역·행·열과 가림 구조물을 제안하고 운영자가 수정한다. 공연 기획사는 해당 공연의 세트·스크린·카메라 위치를 승인한다. 판매 중 좌석 문의에는 승인된 시야 근거를 인용한 AI 답변 초안을 제공하고 담당자가 발행한다.

기본 공연장 모델은 다음 공연에도 재사용한다. 기존 좌석 사진 서비스나 정적인 3D 투어와 비교해 **공연마다 바뀌는 무대 구성**, **가림의 구체적 원인**, **시야 자료의 검증 수준**을 한 구매 화면에서 제공한다. 시야제한석을 반복 판매하는 중형 공연장의 지정좌석 공연을 첫 대상으로 삼는다.

## 3. 실현 가능성

2D 좌석도에서는 PaddleOCR로 번호를 읽고 SAM 2로 운영자가 지목한 구조물을 분할한다. 좌석 간격·단차·난간·무대의 실측 치수로 공연장 공통 모델을 만들고, Three.js에서 **좌석을 바꿀 때 카메라만 이동**해 시야를 계산한다. 반복 좌석은 같은 자산을 공유하고, 재질·조명을 개선해 화질을 높인다. 무대 세트는 공연별 변경분만 갱신한다. Blender는 필요한 자산 제작에 선택적으로 사용한다. 3D 실행이 어려운 기기에는 요청된 좌석의 정적 이미지를 제공·캐시하고, 대표 좌석 실사진으로 가림을 검증한다. 전체 좌석의 360도 이미지를 미리 제작할 필요는 없다. AI는 모델 작성과 문의 답변을 보조하며 승인 자료가 없으면 답변을 보류한다. **2D 이미지 한 장만으로 정확한 디지털 트윈을 자동 완성하지 않는다.** 운영자 승인과 실제 사진 대조가 필수다.

첫 실증은 공연장 한 곳의 서로 다른 좌석 20개와 공연별 무대 구성 두 가지로 실시한다. 실제 좌석 사진을 기준으로 가림 유형 판정 일치율, 좌석 선택 시간·확신도, 담당자의 문의 응답 시간을 측정한다. 초기는 예매·결제를 새로 만들지 않고 공식 예매처로 연결한다. 공연장 기본 모델 제작비와 공연별 배치 갱신비를 제안하고, 반복 제작 시간·좌석 문의·구매 전환 효과를 실증해 가격을 정한다. 예매 채널과 현장 운영 서비스를 제공하는 NHN LINK는 시범 협업 후보이고, 네이버 예약의 회차형 좌석도는 향후 연결을 검토할 접점이다. 제휴가 성립했다는 뜻은 아니며, 예매처 재고·결제 연동은 계약 뒤 추진한다.

## 4. 기대 효과 및 파급력

관객은 같은 가격대 좌석을 시야와 근거를 보고 비교해 관람 후 실망을 줄일 수 있다. 공연장과 기획사는 모호한 주의 문구를 구체적 안내로 바꾸고, 시야제한석을 설명할 자료를 축적한다. 실제 문의 감소나 판매 개선은 추정 수치로 제시하지 않고 실증에서 확인한다. 기본 공간 모델을 재사용하고 공연별 변경분만 갱신하는 방식을 검증하면 뮤지컬·콘서트에서 경기장과 영화관 등으로 확장할 수 있다.

## 5. AI 윤리 및 안전성 고려사항

공연장 도면과 사진은 권한 있는 운영자의 허락을 받아 사용하고 사진 속 관객 얼굴은 가린다. 무대 디자인과 공연별 설치물은 기획사의 허락 범위에서만 표시한다. 시뮬레이션과 실제 사진을 구분하고 촬영일·공연 배치 버전·검증 여부를 표기한다. 배치가 바뀌면 검증 표시를 보류하고 재승인을 받는다. 문의 답변은 자동 발송하지 않고 담당자가 근거를 확인해 승인한다. 앞사람의 키·연출·장비 이동 등 현장 변수를 안내하며 불확실한 좌석에 확정적 시야 점수를 부여하지 않는다.

## 6. 맺음말

시야체크 AI는 공연별 좌석 시야를 **예쁜 3D 화면에서 검증 가능한 예매 정보로** 바꾸는 서비스다. 실제 공연장 한 곳의 좌석 사진과 운영자 피드백으로 정확도와 구매 결정 효과를 먼저 확인하겠다.

AI 활용 고지: OpenAI ChatGPT를 기획 문안·UI 개념도 제작과 기술·시장 자료 탐색에 사용하였다. 실제 시야 정확도와 사업 성과는 아직 검증하지 않았으며 시범 운영에서 측정할 계획이다.
