# Seat Map PDF Extraction Spike

실행일: 2026-10-20 (KST). 대상은 국립아시아문화전당 극장 1의 사용자 제공 공식 좌석배치도 PDF 7개다. 원본 PDF·추출 JSON·미리보기 이미지는 저장소에 넣지 않는다.

## 목적과 범위

좌석 번호가 PDF 텍스트로 제공되는 경우, OCR이나 외부 AI API 없이 블록·행·번호와 **PDF 문서상 텍스트 위치**를 구조화할 수 있는지 검증한다. 실제 좌석 중심, 무대와의 거리, 축척, 높이 또는 3D 시야를 자동 추정하지 않는다.

이번 코드는 **단일 페이지, 벡터 표 경계선, 수평 블록 라벨이 좌석 그리드 위에 있는 배치도**에 한정된 초기 baseline이다. 지원 여부가 불분명하면 블록을 억지로 추정하지 않고 미매칭 후보를 기록한다.

## 실행

Python 3.10 이상 환경에서:

~~~powershell
python -m pip install -r experiments/seatmap-pdf/requirements.txt
python experiments/seatmap-pdf/extract_seats.py "C:\path\to\프로시니엄형 - 608석(기본).pdf" --output-dir experiments/seatmap-pdf/output
python experiments/seatmap-pdf/extract_seats.py "C:\path\to\3분할(小) - 208석.pdf" --output-dir experiments/seatmap-pdf/output
python -m unittest discover -s experiments/seatmap-pdf -p "test_*.py" -v
~~~

출력 경로에는 원본 PDF의 파일명에 대응하는 JSON과 검토용 PNG가 생긴다. PDF 파일 자체는 변경되지 않는다. JSON은 블록·행·번호·블록 포함 좌석 ID·문자 bbox·문자 중심(PDF pt)·미검토 상태를 기록한다.

종료 코드 0은 **자동 무결성 검사 통과**를 뜻할 뿐, 좌석별 정답 검증이나 현장 검수를 의미하지 않는다. 미매칭·중복·표기 좌석 수 불일치 또는 블록 경계 추출 실패 시 종료 코드 2를 반환한다.

## 로컬 실행에서 확인한 결과

환경: Python 3.13.5, PyMuPDF 1.26.7. 사용자 제공 PDF를 읽기 전용으로 분석했다. 좌석 번호는 숫자-숫자 형태의 PDF 텍스트 단어로 확인했다.

| 배치 형태 | 문서 표기 좌석 수 | PDF 좌석 텍스트 | 블록 연결 후보 | 미매칭 | 자동 검사 |
| --- | ---: | ---: | ---: | ---: | --- |
| 기본 프로시니엄 | 608 | 608 | 608 | 0 | 통과 |
| 3분할(小) 208석 | 208 | 208 | 208 | 0 | 통과 |
| 3분할(小) 224석 | 224 | 224 | 224 | 0 | 통과 |
| 3분할(大) 384석 | 384 | 384 | 384 | 0 | 통과 |
| 돌출형 | 832 | 832 | 608 | 224 | 실패 |
| 로드형 | 560 | 560 | 0 | 560 | 실패 |
| 아레나형 | 944 | 944 | 608 | 336 | 실패 |

숫자는 이 추출기를 동일한 7개 파일에 실행해 얻은 **기계적 후보 수**다. 좌석별 수작업 전수 대조를 하지 않았으므로 '608/608'을 인식 정답률 100%라고 표현할 수 없다. 다른 공연장에서의 일반화도 검증하지 않았다.

기본 프로시니엄 배치의 후보 집계는 A~J블록 각 56석, FOH 48석이다. 208석 배치는 A·B 각각 56석, C·D 각각 48석이다. 208석과 224석을 비교하면 208석의 C블록에서는 6·7행의 5~8번, D블록에서는 6·7행의 1~4번이 빠져 있어 총 16석 차이가 난다. 이는 두 PDF에 표시된 좌석의 비교이지 실제 설치 상태의 증거는 아니다.

실패한 세 배치에는 무대 측면·후면 좌석과 수직 또는 다른 위치에 배치된 블록 라벨이 있다. 현재 코드는 수평 라벨 바로 아래의 표 상단 선분만 탐색하므로 이를 연결하지 못한다. 미매칭을 다른 블록에 억지로 할당하지 않는 것은 의도적 동작이다.

## 테스트 및 검증 범위

- 합성 벡터 PDF에서 반복 좌석 번호의 블록 분리
- 상단 경계선이 없는 블록의 자동 미매칭 처리
- 문서 표기 좌석 수와 추출 개수 불일치 감지
- 다중 페이지 PDF의 명시적 거부

합성 fixture 기반 표적 단위 테스트 4개가 실행돼 통과했다. 실제 PDF는 저장소 테스트 fixture나 CI에 포함하지 않는다.

## 데이터·서비스 제약

공식 웹사이트에서 공개된 PDF라도 재배포 또는 ML 학습 허용이 확인된 것은 아니다. 사용자가 확보한 사본은 로컬 분석에만 사용하고, 제3자 공유·학습 데이터셋 구성 전에는 적용되는 이용 조건을 별도로 확인한다.

PDF 텍스트 위치는 의자의 물리적 중심이 아니다. 무대 폭·좌석별 단차·가림 구조물 등의 실측 정보가 없으므로 현재 convertPlan 경로에 그대로 넣지 않는다. 기존 제품 코드는 변경하지 않았으며 유료 클라우드·VLM·OCR 호출도 수행하지 않았다.

PyMuPDF는 AGPL/상용 라이선스 체계를 제공한다. 비공개 상용 제품에 결합하기 전에 라이선스 적합성을 검토해야 한다.
